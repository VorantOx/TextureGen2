# OTWNDATA — бесшовные PBR-текстуры каменной стены

Этот пак содержит **только стены**. Пол и потолок генерируются в редакторе
(`otwn_editor.py`) в отдельном направлении «Пол и потолок»: регулярная
плитка по шаблонам, с теми же палитрами `gold` / `aged` / `cyclopean`.
Готовые карты публикуются в `textures_otwn/<variant>/floor/` и
`textures_otwn/<variant>/ceiling/`.

Стиль: тайлы стен OTWNDATA.VGA (Wizardry VII, 1992), тайл t000.
Текстуры синтезированы процедурно и бесшовно; это не апскейл
8-битных тайлов, а новая кладка в той же палитре и манере.

## Кладка
- 49 крупных камней и 16 средних камней в естественных развилках
  швов. Все камни — ячейки одной периодической степенной диаграммы,
  поэтому средние камни не накладываются на крупные, а занимают
  свободные полости между ними.
- Крупные камни — сложные многоугольники без ограничения числа
  сторон, плотно упакованные. Углы скруглены периодическим
  раскрытием, поэтому силуэты выглядят обкатанными, а не
  многогранными.
- Разброс линейного размера крупных камней — около 4.0x (max/min).
  Фактически по вариантам:
    gold       max/min = 3.55  (255 %)
    aged       max/min = 4.03  (303 %)
    cyclopean  max/min = 3.95  (295 %)
- Швы узкие: 10 px при 2048 для gold/aged и 9 px для cyclopean.
  В карте высот край камня имеет широкую мягкую фаску, а стык —
  неглубокую полосу раствора без узких ям и чёрных провалов.
  Тело камня остаётся куполообразным.
- Переход цвета от шва к камню мягкий: тёмная линия шва
  переходит в основной цвет через плавную полосу раствора,
  без резкой границы.
- В normal map основная площадь камня имеет мелкую грубую
  обработку. У швов детализация плавно сходит на нет, поэтому
  округлый силуэт и широкая фаска читаются мягко, без ступеней.
- height, roughness и AO используют ту же широкую зону перехода
  у края камня, что и albedo; это убирает рассинхрон карт.
- Ширина мягкой зоны задана в долях радиуса камня, поэтому
  средние и мелкие камни получают такой же плавный градиент, как
  крупные. На стыке крупного и среднего камня ширина считается
  по локальному минимуму радиуса, поэтому она не прыгает на
  границе. Контраст у мелких ниже, чтобы тёмный раствор не
  превращал небольшой камень в одно тёмное пятно.
- Сколы/выщербины: 15 на текстуру, от мелких точек до крупных
  выломов. В альбедо они почти не читаются, а в height/normal/AO
  дают заметный рельеф.
- Трещины: процедурная генерация реализована, но по умолчанию
  отключена. Включить можно параметром --cracks N.

## Палитра (sRGB, взята из OTWNDATA t000)
  #d2b662, #d2aa50, #c29948, #b28944, #9a7433 — золотистый песчаник
  #d4b018 — жёлтые минеральные вкрапления
  #eeb17d — лососёвые/розовые вкрапления
  #6d501e / тёмно-коричневый — раствор и грязь в швах

## Варианты
gold/       — золотисто-песчаная кладка, ближе всего к оригиналу
aged/       — выветренная, темнее, с мхом в швах
cyclopean/  — более высокие купола, более контрастная кладка

## Файлы (каждый вариант, 2048x2048)
albedo_2k.png       — базовый цвет (sRGB)
height_2k.png       — карта высот (линейная, grayscale)
normal_gl_2k.png    — normal map, OpenGL (+Y вверх)
normal_dx_2k.png    — normal map, DirectX (-Y)
roughness_2k.png    — шероховатость (линейная, grayscale)
ao_2k.png           — ambient occlusion (линейная, grayscale)

## Свойства
- Все карты бесшовные по X и Y.
- albedo — sRGB; height / normal / roughness / ao — линейные данные.
- normal_gl: зелёный канал +Y; normal_dx: зелёный канал -Y.
- Камень немагнитный: metallic = 0.
- Масштаб: 7 крупных камней по ширине текстуры; средние камни
  занимают развилки швов и заметно меньше крупных.

## Three.js (MeshStandardMaterial)
  const tex = new THREE.TextureLoader();
  mat.map = tex.load('gold/albedo_2k.png');
  mat.normalMap = tex.load('gold/normal_gl_2k.png');
  mat.roughnessMap = tex.load('gold/roughness_2k.png');
  mat.aoMap = tex.load('gold/ao_2k.png');
  mat.metalness = 0.0; mat.roughness = 1.0;
  mat.map.colorSpace = THREE.SRGBColorSpace;
  // aoMap требует второго UV-набора (uv2) в геометрии.

## Генерация
  python make_otwn_textures.py
  python make_otwn_textures.py --size 512 --variants gold  # быстрый тест

## Параметры
  --joint PX   полная ширина шва в пикселях при 2048 (по умолчанию
               10 для gold/aged и 9 для cyclopean). 0 — не
               генерировать средние камни, оставить тонкий тёмный
               шов-раствор.
  --dome K     амплитуда купола крупных камней, 1.0 — обычная,
               0.0 — плоские верхние грани (остаётся фаска у шва).
  --chips N    число сколов (по умолчанию 15, максимум stones/3).
  --cracks N   число трещин (по умолчанию 0 — отключено).
  --spread K   целевой разброс линейного размера крупных камней
               (по умолчанию 4.0).
  --medium N   максимум средних камней в развилках (по умолчанию 16).
  --medium-area F  доля площади под средние камни (по умолчанию 0.09).
  --seam-halo F    ширина общей мягкой зоны у шва (доля размера,
                   по умолчанию 0.005).
  --seam-halo-amt F  сила градиента цвета у шва (0..1, по умолчанию 0.30).
  --normal-detail K  сила мелкой шероховатости normal map (по умолчанию 1.0).

Примеры:
  python make_otwn_textures.py --joint 0 --dome 0
  python make_otwn_textures.py --cracks 9 --size 512 --variants gold
  python make_otwn_textures.py --spread 3.0 --medium 12
